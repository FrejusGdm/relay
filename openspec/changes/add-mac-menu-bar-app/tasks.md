# Tasks

Build this change only after `add-daemon-api-and-status` is merged. Every task is one small pull
request. Nothing in `mac/` is built or tested on Josué's Mac or on Omarchy: the code is edited on
the Mac, pushed, and the `mac-app.yml` workflow builds and tests it on the `macos-26` runner. Task
2.5 is the exception; it is a Bun test that runs on Omarchy like the rest of the Bun suite.

Every task that changes `mac/` is verified with these commands, run on the Mac after pushing the
branch and opening its pull request (`<branch>` is the task's branch; design decision 15):

```sh
run=$(gh run list --workflow mac-app.yml --branch <branch> --limit 1 --json databaseId --jq '.[0].databaseId')
gh run watch "$run" --exit-status
gh run view "$run" --log | grep -E 'Test run with|Smoke test passed|Built mac/build'
```

`gh run watch --exit-status` must exit 0, and the `grep` must show "Test run with N tests in M
suites passed", "Built mac/build/Relay-macOS.zip" and "Smoke test passed". Where a task names a test
suite, `gh run view "$run" --log | grep -E '<suite name>'` must show it passing. Screenshots are read
with `gh run download "$run" --name mac-app-screenshots --dir "$TMPDIR/mac-shots-$run"`. Section
numbers ("decision 8") refer to design.md.
