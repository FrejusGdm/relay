# Tasks

Every task is one small pull request. Following AGENTS.md, code is edited on the Mac and installed,
built and tested on the Omarchy machine (the `jstack-remote-build` skill); tasks marked "also on
the Mac" need macOS because they test `getpeereid`, and only run `bun test` there. In the
commands, `$RELAY_HOME` is a fresh folder made with `mktemp -d /tmp/relay-test-XXXX`, and
`SOCK="$RELAY_HOME/run/relay.sock"`. Section numbers ("decision 3") refer to design.md.
