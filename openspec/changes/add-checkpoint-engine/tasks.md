# Tasks

Each numbered task fits in one small pull request. Following AGENTS.md, edit on the Mac and run every command below on the Omarchy machine (see the `jstack-remote-build` skill), from the repository root. Every test creates its scratch repositories and `RELAY_HOME` under a fresh `relay-test-` folder in the system temporary folder and removes it afterwards. Integration tests need git 2.34 or newer and gitleaks 8.28 or newer on `PATH`; they fail with a clear message, never skip, when either is missing. `bunx tsc --noEmit` must pass after every task.
