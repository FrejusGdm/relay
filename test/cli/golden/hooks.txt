Usage
  relay hooks <install|remove|status> <provider:name>

Add, remove or check relay's hooks for an account.
Hooks let relay see when an agent stops or reaches a limit.

Examples
  relay hooks install claude:personal
  relay hooks install claude:personal --status-line
  relay hooks status codex:personal
  relay hooks remove claude:personal

Options
      --status-line        install: also record usage from Claude Code's status line
      --yes                install, remove: do not ask
  -h, --help               Show this help
      --log-level <level>  How much to log: debug, info, warn or error
