Same task, different worker

Every job records which agent worked on it, when it stopped, and the checkpoint where the next one started.

Switch from the terminal.

One command stops the current agent, saves a checkpoint and starts the next one. Then relay status shows where the work went.

~/projects/relay-auth 
$ relay switch codex:personal

Stopping  Claude Code · claude:personal
Saved     checkpoint 912ec1 · 3 files · 231 passed, 1 failed
Wrote     .relay/checkpoint.md
Starting  Codex · codex:personal

Continuing on Codex.

Bold marks the active account, dim marks the limited one and a dotted line marks an unknown one, so the output reads the same without color.

One agent or a hundred.

Split a job into tasks and each one runs on an account with room left. When an account reaches its limit, its tasks stop at a checkpoint and resume when it resets.

Your agents should be disposable. Your work shouldn’t be.
